# ใบเสร็จรับเงิน - บ้านพักใจ

```bash
npm install
npm run dev     # เปิด http://localhost:3000
```

- เลือกรายการจาก "แพ็กเกจ/ค่าบริการ" (BPJ-001 ถึง BPJ-035) หรือกด "+ เพิ่มรายการอื่น" / "+ เพิ่มส่วนลด"
- ราคาแก้ได้ทุกบรรทัด ช่องส่วนลดจะหักออกจากยอดรวม
- กด **Export PDF** แล้วเลือก "Save as PDF" (ขนาด A4) ชื่อไฟล์จะตั้งเป็น `ใบเสร็จรับเงิน_คุณ<ชื่อ>` ให้อัตโนมัติ
- ข้อมูลบันทึกในเบราว์เซอร์อัตโนมัติ, "บันทึก/เปิด" ใช้เก็บเป็นไฟล์ JSON
- รายการแพ็กเกจแก้ได้ที่ `lib/packages.ts`
